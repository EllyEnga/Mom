# A Celebration for Mom

A small static celebration website with a welcome screen, fixed page-style sections, a navigation menu, photo gallery, video, and celebration music.

## Open locally

Keep `index.html`, `style.css`, `script.js`, and the media files in the same folder, then open `index.html` in a modern browser.

## Media files

Add these files beside `index.html`:

- `mom.jpg` — main photograph
- `mom1.jpg`, `mon2.jpg`, `mom3.jpg`, `mom4.jpg` — gallery photographs
- `mom.mp4` — celebration video
- `congratulations.mp3` — celebration song

The website attempts to start the song when the surprise opens. Mobile browsers may block autoplay; if so, the first tap starts the music. This is a browser security restriction.

## Navigation

The menu bar switches between Home, Message, Memories, Video, and Music. Each is a fixed screen rather than part of one long scrolling page. The menu remains available while switching pages.
